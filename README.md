# Town Editor

A console-based C++ application for managing a virtual town. The application allows users to create, modify, save, and load towns containing stations, buildings, and citizens.

### Features

* Create and customize towns
* Manage residential buildings and facilities
* Manage citizens, including their homes, workplaces, occupations, and salaries
* Create and manage stations
* Connect stations with routes
* Save and load towns

### Technologies

* C++
* OOP
* JSON persistence with [nlohmann/json](https://github.com/nlohmann/json)
* C++17 `std::filesystem` for save-file management
